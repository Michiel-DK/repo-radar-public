## Headline — the agent-skills wave grew a *safety + observability* layer

For two weeks the radar tracked agent **skills** going format → ecosystem → methodology. This snapshot shows the next stage: the ecosystem is now growing the **tooling that wraps skills**, not just more skills.

- **[NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector) (#2)** — a *security scanner for AI agent skills* (detects vulnerable / malicious skills). When NVIDIA ships a scanner for a category, that category has arrived — and it confirms a real risk in the skills gold-rush.
- **[agentsview](https://github.com/kenn-io/agentsview) (#6)** — local-first *search + token analytics over agent sessions*: the observability layer for agents.

> Read together: skills are no longer the story — **securing and observing** agent systems is.
