## Headline — the board rotated from "named-agent loadouts" to **security agents + cost/token economy**

Last week (07-01) the top of the board was the *skills / named-agent-loadout* wave (agency-agents #1, superpowers #6, Google's agents-cli). This week that wave **cooled** — agency-agents slid to #2 and appeared only 5 of 7 days, superpowers to #10 / 3 days. Two different threads took over:

- **Security-as-agents went to #1.** [strix](https://github.com/usestrix/strix) — autonomous AI pentesters that find *and fix* vulnerabilities — was the single biggest star-accumulator of the week (9.7k) and a **6-day persister**. It sat at #12 last snapshot; it now owns the board. The cyber/trust theme has been producing supply for weeks and this week it graduated to the top.
- **The cost/token-economy thread got loud on BOTH sides.** New at #3, [caveman](https://github.com/JuliusBrussee/caveman) is a Claude Code skill whose entire pitch is *token compression* ("why use many token when few token do trick"). Pair it with [OmniRoute](https://github.com/diegosouzapw/OmniRoute) (#7, now a 6-day persister — up from "just off the table" last week), a free gateway fronting 231+ providers with auto-fallback. On the **demand** side, HN carried *"AI's Affordability Crisis"*, *"GLM 5.2 vs Opus"*, *"Why is there no US open-weights model?"* and *"Tokenmaxxing is dead, long live tokenmaxxing"* — **every single day of the week**. Supply and demand are now pointing at the same thing: cheaper, provider-independent inference.

## Trends I notice

- **Cross-harness interop is now a first-class category.** [openai/codex-plugin-cc](https://github.com/openai/codex-plugin-cc) (#9) lets you drive **Codex from inside Claude Code**; HN had *"Kimi K2.7 Code is generally available in GitHub Copilot"* and *"ZCode — Harness for GLM-5.2."* The agent world is converging on "any model, any harness" — the same portability thesis as the cost thread, one layer up.
- **Agent-fleet & agent-driven-surface tooling keeps compounding.** [herdr](https://github.com/ogulcancelik/herdr) (#6, 7-day persister) for running many agents at once; [chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp) (6d) and [page-agent](https://github.com/alibaba/page-agent) (#13) for agents *operating* real UIs. As people run fleets, the supervise-and-drive layer thickens.
- **"Agent-ready" is leaking into non-agent categories.** [facebook/astryx](https://github.com/facebook/astryx) (#4) — a **design system** that markets itself as "agent-ready," and it was present *every one of the 7 days*. When Meta ships UI infra framed around agents consuming it, the framing has gone mainstream.
- **On-device / privacy AI as its own cluster.** [meetily](https://github.com/Zackriya-Solutions/meetily) (#12, local meeting assistant) + [FluidVoice](https://github.com/altic-dev/FluidVoice) (#15, on-device dictation) + [simplex-chat](https://github.com/simplex-chat/simplex-chat). Data-sovereignty is showing up as consumer product, not just enterprise talking point.
- **Finance/value-investing agents persist (but as skill/MCP packs, not SaaS).** [Vibe-Trading](https://github.com/HKUDS/Vibe-Trading) (#8, 5d) and [ai-berkshire](https://github.com/xbtlin/ai-berkshire) (#14) carried over from last week. Same *"domain expertise → skill bundle → multi-agent research loop"* packaging as everything else — treat the track-record claims as marketing, keep the shape.
